# 🧩 Local Skin Changer

## ✨ What this mod does
🧍 Replaces **only your local player’s rendered skin** (client-side)  
🏠 Adds a **home menu (Title Screen) “Skins” button**  
🛏️ Opens a simple **Bedrock-style skin picker** with 2 skins to equip  
🌐 Does **not** change your Mojang/Microsoft account skin  
👥 Does **not** change what other players see on servers

## 🧥 Available skins
🦆 Blob Duckie  
🔳 Inverted  

## 🕹️ How to use
1. 🏠 Open Minecraft to the Title Screen  
2. 🔘 Click **Skins** (bottom-left)  
3. ✅ Click **Equip** on the skin you want  

## 🧰 Install
📦 Put the built jar in your `mods` folder  
🧵 Requires Fabric Loader + Fabric API for the matching Minecraft version  

## 🧪 Build
### 🧱 Minecraft 1.20.4
```bash
gradle :mod-1_20_4:build
```

### 🧱 Minecraft 1.21.x
```bash
gradle :mod-1_21_x:build
```

### 🧱 Minecraft 26.x
```bash
gradle :mod-26_x:build
```

## 💾 Config
📄 Saved at `config/local_skin_changer.json`  
🔁 The selected skin persists between launches
