# 👕 Skin Changer Mod 🎭

A client-side Minecraft mod that allows you to change your skin locally! 🌟

## ✨ Features

- 🔄 **Local Skin Swap**: Change your avatar without affecting others.
- 🔒 **Client-Only**: Only YOU see your new look! 👤
- 🖥️ **Bedrock-Style Menu**: A familiar interface to pick your style. 🎮
- 🌐 **Online Skins**: Support for direct skin URLs. 🔗

## 🚀 How to Use

1. ⌨️ Press **'K'** in-game or find the 👕 button in the Escape Menu.
2. 🖱️ Select one of the available skins.
3. ✨ Enjoy your new look!

## 📦 Available Skins

- 🐥 **Blob Duckie**
- 🌓 **Inverted**

## 🛠️ Requirements

- 🧩 Fabric Loader
- 🧱 Minecraft 1.21
- ⚙️ Fabric API
